# QuantPort library

Each board is one model × GPU, one row per method, measured on WikiText-2
against the original fp16 checkpoint. Ranked by `quality_ok`, then tok/s,
then lower VRAM.

The vLLM column links a vLLM build of the same weights. The vLLM table under
a board is measured on the GPU it names, with plain Transformers alongside.
It never changes the ranking.

Weights: [Hugging Face collection](https://huggingface.co/collections/chris320211/quantport-library-6aaf22fcafd69b39eabc9230). Unsuccessful runs: [ATTEMPTS.md](ATTEMPTS.md).
Generated by `library.py`; to add a row, see [contributions](contributions/README.md).
